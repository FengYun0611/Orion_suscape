## How It Works

### Trajectory Evaluation Pipeline

1. **Ground Truth (GT)**: Loaded from **q7 (端到端轨迹预测)** QA task
   - Provides precise VLM-annotated trajectory waypoints
   - Fallback to CSV if q7 data unavailable for a frame

2. **Prediction**: Generated by **ORION model**
   - Model processes multi-view camera images
   - Generates future trajectory predictions (6 waypoints @ 2Hz = 3 seconds)

3. **Metrics Computation** (following main branch methodology):
   - **L2 Error**: Euclidean distance between predicted and GT trajectories
   - **Collision Rate**: Ratio of trajectories colliding with obstacles
   - Computed at: 1s, 2s, 3s horizons + average

## Metrics Explanation

### L2 Trajectory Error
- **Lower is better**
- Measured in meters
- Average Euclidean distance between predicted and GT waypoints
- Computed using the formula: `√((x_pred - x_gt)² + (y_pred - y_gt)²)`

### Collision Rate
- **Lower is better**
- Range: 0.0 to 1.0 (0% to 100%)
- Proportion of trajectories that would collide with:
  - **Object Collision**: Any detected obstacle
  - **Box Collision**: Considering full vehicle bounding box (more conservative)

### Time Horizons
- **1s**: Trajectory at 2 waypoints (0.5s × 2)
- **2s**: Trajectory at 4 waypoints (0.5s × 4)
- **3s**: Trajectory at 6 waypoints (0.5s × 6)
- **Avg**: Mean of 1s, 2s, and 3s metrics

## QA Task Roles

| Task ID | Purpose | Used For |
|---------|---------|----------|
| **q7** | 端到端轨迹预测 (End-to-end trajectory prediction) | **Primary GT** for L2 evaluation |
| q1 | VRU identification | Future: Object detection eval |
| q2 | Motion intent prediction | Future: Intent recognition eval |
| q5 | Scene description | Future: Scene understanding eval |
| q10-q12 | Safety/Comfort/Compliance | Future: Multi-criteria evaluation |

**Current Implementation**: Only q7 is actively used for trajectory GT. Others are loaded if specified but not yet used in metrics.

## Troubleshooting

### Issue: "QA file not found"

**Solution**: Check your `qa_root` path. If QA dataset is in `suscape_scenes_vlm_label/sharegpt_dataset/`, use:
```python
qa_root = "data/suscape_scenes_vlm_label/sharegpt_dataset"
```

### Issue: "No QA trajectory loaded"

**Possible causes**:
1. q7 JSON file is missing or empty
2. Scene IDs in JSON don't match scene directory names
3. Frame indices don't align

**Debug**:
```bash
# Check if q7 exists
ls -la data/suscape_scenes_vlm_label/sharegpt_dataset/suscape_NQA_q7.json

# Check JSON structure
python -c "import json; data=json.load(open('data/suscape_scenes_vlm_label/sharegpt_dataset/suscape_NQA_q7.json')); print(f'Loaded {len(data)} items'); print(data[0].keys())"
```

### Issue: "All metrics are 0.0"

**Cause**: No valid samples (all trajectories incomplete)

**Solution**: Check that:
- Scenes have sufficient frames (at least 7 frames for 3s prediction)
- CSV files contain ego vehicle data
- Camera images exist for all required frames
